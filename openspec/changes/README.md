# Active Changes

Each change gets a lowercase-kebab-case directory containing:

- `proposal.md` — why and what changes
- `design.md` — technical approach and tradeoffs
- `tasks.md` — ordered, verifiable implementation work
- `specs/<capability>/spec.md` — ADDED, MODIFIED, or REMOVED requirement deltas

Move completed changes to `archive/YYYY-MM-DD-<change-name>/` after canonical
specifications are synchronized.
