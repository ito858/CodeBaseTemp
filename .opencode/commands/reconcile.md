Use the knowledge-maintenance skill. Reconcile `$ARGUMENTS` (or the relevant project
area when omitted). Compare approved specs and ADRs with architecture records, active
OpenSpec changes, state files, and implementation. Report conflicts with links and
evidence; classify each as specification drift, implementation drift, stale state, or
an unanswered product decision. Do not silently rewrite authoritative records. Propose
the smallest specific updates and request decisions where authority cannot resolve it.
