---
description: Create an OpenSpec-compatible proposed change without requiring the CLI
---

Use the knowledge-maintenance skill. Create a proposed OpenSpec-compatible change
named `$1` under `openspec/changes/`. Read relevant canonical documentation and code.
Create `proposal.md`, `design.md`, `tasks.md`, and only the needed spec-delta files in
`specs/<capability>/spec.md`. Include rationale, scope, non-goals, requirements and
scenarios, technical decisions, verification, documentation impacts, dependencies,
risks, and unresolved questions. Do not begin implementation; request approval.
